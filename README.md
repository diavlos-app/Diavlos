# Δίαυλος — Προσβάσιμη Επικοινωνία

Εργαλείο επικοινωνίας για κωφούς και βαρήκοους. Λειτουργεί και χωρίς σύνδεση (PWA).

## Λειτουργίες
- **Κάρτες**: έτοιμες φράσεις ανά κατηγορία (Υπηρεσίες, Ψώνια, Καφέ/Φαγητό, …), ανάγνωση φωνητικά, εμφάνιση σε μεγάλα γράμματα, «Απάντηση» από τον συνομιλητή (αριθμός / κείμενο / ΝΑΙ-ΟΧΙ / ημερομηνία)
- **Έκτακτη ανάγκη**: έτοιμο SMS προς το 112 (ποτέ κλήση) και οθόνη ΝΑΙ/ΟΧΙ για επικοινωνία στο σημείο
- **Αγαπημένα** με tags και **Ιστορικό** απαντήσεων (εξαγωγή σε PDF) — αποθηκεύονται μόνο τοπικά στη συσκευή
- **Χάρτης** με σημεία προσβασιμότητας και δεδομένα OpenStreetMap
- Μεταγραφή: σε εξέλιξη (`test-transcription.html` = πειραματικός έλεγχος συμβατότητας συσκευής)

## Τοπική δοκιμή
Χρειάζεται τοπικός server (ο service worker δεν δουλεύει με file://):

```bash
python3 -m http.server 8000
```

## Δημοσίευση (Cloudflare Pages)
Στατικό site χωρίς build step: output directory = ρίζα του repo. Το `_headers` ορίζει COOP/COEP.

## Όταν αλλάζεις αρχεία
Ανέβασε το `CACHE_NAME` στο `sw.js` και το `?v=` στα `<script>` του `index.html`.

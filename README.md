# Δίαυλος — Tab 1 σκελετός (Κάρτες Συζήτησης)

## Τι υπάρχει τώρα
- Λίστα κατηγοριών (ΚΕΠ, Γενικά, + "Οι Κάρτες μου")
- Κάρτες με μεγάλο κείμενο + κουμπί "🔊 Ανάγνωση" (χρησιμοποιεί το ενσωματωμένο
  Text-to-Speech του browser/κινητού, δωρεάν, χωρίς API)
- Δυνατότητα προσθήκης προσωπικών καρτών (αποθηκεύονται ΤΟΠΙΚΑ στη συσκευή
  μέσω localStorage — καμία σύνδεση με server, καμία ταυτοποίηση)
- Πλήρης λειτουργία offline μέσω service worker
- Tab bar στο κάτω μέρος, με τα Tabs "Χάρτης" και "Μεταγραφή" ήδη ορατά αλλά
  απενεργοποιημένα ("Έρχεται σύντομα") — έτοιμα να ενεργοποιηθούν στα επόμενα βήματα

## Πώς να το δοκιμάσεις τοπικά
Χρειάζεται τοπικός server (όχι απευθείας άνοιγμα του index.html) γιατί ο
service worker δεν δουλεύει με το file:// πρωτόκολλο:

```bash
cd diavlos
python3 -m http.server 8000
```

Μετά άνοιξε http://localhost:8000 στον browser.

## Πώς να το ανεβάσεις (ίδιο μοντέλο με το KOK 2025)
1. Δημιούργησε νέο repo στο GitHub (π.χ. `Diavlos`)
2. Ανέβασε όλα τα αρχεία αυτού του φακέλου
3. Settings → Pages → ενεργοποίησε GitHub Pages από το main branch
4. Θα είναι διαθέσιμο στο `https://<username>.github.io/Diavlos/`

## Εκκρεμότητες πριν το πρώτο πραγματικό test
- **Εικονίδια**: το manifest.json αναφέρει `icon-192.png` και `icon-512.png`
  που δεν υπάρχουν ακόμα — χρειάζεται να φτιαχτούν/επιλεγούν πριν γίνει
  installable ως πλήρες PWA. Μπορούμε να το κάνουμε στο επόμενο βήμα.
- Το κείμενο των καρτών ΚΕΠ είναι ενδεικτικό — θα χρειαστεί να τα δούμε μαζί
  και να τα επεκτείνουμε/διορθώσουμε πριν θεωρηθεί έτοιμο περιεχόμενο.

## Δομή αρχείων
```
diavlos/
├── index.html      → δομή σελίδας, tab bar
├── style.css        → εμφάνιση, μεγάλα γράμματα, dark mode aware
├── app.js            → λογική (rendering καρτών, TTS, custom κάρτες)
├── data.js            → περιεχόμενο καρτών ανά κατηγορία
├── manifest.json       → PWA metadata
└── sw.js                → offline caching
```
